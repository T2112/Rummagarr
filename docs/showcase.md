## Portfolio

Rummagarr is a personal Windows desktop app that searches Soulseek for the albums and tracks a Lidarr library is still missing, downloads the files, and asks Lidarr to import and rename them. It keeps a Wanted list on the PC, with Search, Browse, and Messages on the same Soulseek login, and a long download shows a progress count and Cancel. An optional bridge lets Lidarr search Soulseek through a local Torznab indexer and a qBittorrent-compatible API. The source and the self-updating Windows installer are published at T2112/lidarr-soulseek.
